- `images/electrician.jpg` is the approved Emmanuel Ikwuegbu photograph from Pexels, copied unchanged from the web marketing assets. Native font weight, photography crops and system surfaces still need physical Android/iOS visual review. No customer or provider uploads are copied into this project.
