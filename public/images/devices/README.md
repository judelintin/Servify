# Current device presentation — iPhone 11 style

The current website component consumes `iphone-11-frame.svg`, original resolution-independent vector artwork created on 18 November 2026. It is not an official Apple asset, product photograph or licensed third-party mockup.

The 454 × 906 exterior follows the approximately 75.7:150.9 physical width:height ratio in [Apple's iPhone 11 specifications](https://support.apple.com/en-us/111865). The screen is 390 × 844, the same aspect ratio as the published 828 × 1792 display. The graphic includes rounded bezels, inset glass, side buttons, a connected wide notch, speaker/camera details and a home indicator. There is no Dynamic Island. Hardware neutrals use existing Servify token values; typography remains Inter Tight.

Genuine 1170 × 2316 screenshots of a 390 × 772 app viewport are positioned at their exact aspect ratio inside the screen. Separate 48px status and 24px bottom regions complete the screen without stretching the capture, covering app controls or fabricating application UI. Next Image provides responsive high-density image delivery. Subtle shadows and perspective remain restrained.

The superseded `iphone-frame.svg` is no longer referenced. It was preserved with a matching SHA-256 hash in ignored local `artifacts/stage10b/checkpoint-archive/public/images/devices/` and excluded from the public checkpoint. No mockup library, purchase, Apple branding asset or new dependency was required.
