# Service icon provenance

These six original Servify placeholder vectors were authored for Stage 02, using
one 24px, 1.7px monoline treatment. They are not exported from or traced from Figma.
The Figma plugin hit its connected-plan call limit and the desktop fallback failed
to start, so fresh comparison/export could not be completed. Revisit the supplied
Figma variants and their source licenses before approving final category artwork.
All use the primary blue and appear beside visible category text, never as the logo.
